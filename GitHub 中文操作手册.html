GitHub 中文操作手册

手把手教你新建仓库、上传文件、删除文件、删除仓库，每一步都告诉你点哪里

📑 目录

  1. 新建公开仓库（所有人都能看到）
  2. 新建私有仓库（只有自己能看到）
  3. 上传文件到仓库
  4. 删除仓库里的文件
  5. 删除整个仓库

📦 新建公开仓库 公开

公开仓库所有人都可以在网上看到，适合开源项目。操作全程在网页上完成，不需要装任何软件。

1
登录 GitHub，点击右上角 ➕ 号
打开 github.com 并登录。① 在页面右上角找到你的头像左边有一个 "+" 号按钮，点击它。

📸 下图红框位置就是 "+" 号按钮

🔍 搜索 ① 点这里 + 头像 ▼
➡️ 点击 "+" 后弹出的菜单里选择 "New repository"（新建仓库）
2
填写仓库信息
跳转到新建仓库页面后，你需要填写以下几项：
Create a new repository
② Owner：选你自己（默认就是你的账号）
③ Repository name：输入仓库名，比如 my-project
④ Description（选填）：写一句描述，比如「我的第一个项目」
⑤ Public / Private：选 Public（公开，所有人都可见）
⑥ Add a README file：勾上，自动生成说明文件
💡 提示：仓库名只能用英文、数字、横线(-)、下划线(_)，不能用中文和空格。
3
点击 "Create repository" 绿色按钮
页面拉到最下面，有一个绿色的 "Create repository" 按钮，点击它。几秒钟后仓库就创建好了，会自动跳转到仓库页面。
✅ 创建完成！你会在新页面上看到你的仓库，里面有一个自动生成的 README.md 文件。

🔒 新建私有仓库 私有

私有仓库只有你自己（和你添加的协作者）能看到，适合公司项目或个人代码。

1
跟公开仓库的前两步一样
登录后点右上角 ➕ → "New repository"，然后填写仓库名。
2
关键一步：选 Private
在仓库信息页面的 "Public / Private" 选项处，选择 Private（私有）。这就是公开和私有的唯一区别。
Public
任何人都能看
Private ← 选这个
只有你能看
3
点击创建
勾选 README，然后点击绿色 "Create repository" 按钮，私有仓库就建好了。页面上会在仓库名旁边显示一个 "Private" 标签，表示这是私有的。

📤 上传文件到仓库

不用装 Git 软件，直接在浏览器里上传文件，适合小文件、配置文件、图片等。

1
进入你的仓库页面，找到 "Add file" 按钮
打开你的仓库（比如 github.com/你的用户名/项目名），在文件列表的右上方，有一个 "Add file" 下拉按钮。

📸 仓库页面上方靠右的位置，"Code" 绿色按钮左边，就是 "Add file"

📁 你的仓库名 Go to file ① Add file ▼ Code ▼
2
选择 "Upload files"
点击 "Add file" 后弹出两个选项：
Create new file（新建文件）
Upload files（上传文件）← 选这个
3
拖拽或选择要上传的文件
进入上传页面后，你可以：
  • 直接把文件从电脑文件夹拖进来
  • 或者点击 "choose your files" 从文件选择框里选

📸 页面上有一个很大的虚线框，写"Drag files here to add them to your repository"，就是这里拖文件

⚠️ 注意：每次上传最多 100 个文件，单个文件不能超过 25MB。大文件需要用 Git 或 Git LFS。
4
填写提交信息，点击 "Commit changes"
上传完文件后，页面往下拉：
  • Commit message（必填）：写一句说明，比如「添加了配置文件」
  • Extended description（选填）：详细说明
  • 然后点击绿色的 "Commit changes" 按钮
✅ 文件就上传成功了，页面会自动跳回仓库，你会看到新文件出现在文件列表里。

🗑️ 删除仓库里的文件

直接在网页上删除文件，不需要装任何软件。每个文件都可以单独删除。

1
进入仓库，找到要删除的文件
打开你的仓库，在文件列表里点击你要删除的那个文件（不是勾选框，是文件名）。

📸 文件列表里每个文件名都是蓝色可点击的链接，点一下进入文件详情页面

2
点击文件右上角的 垃圾桶图标 🗑️
进入文件详情页后，在文件内容的上方工具栏里，找到 垃圾桶图标（Delete this file）。鼠标移上去会显示 "Delete this file"。点击它。
📄 README.md ✏️ ① 🗑️ 点这里删除 ⋯
3
确认删除，点击 "Commit changes"
点击垃圾桶后，GitHub 会要求你确认：
  • Commit message：GitHub 会自动填好 "Delete 文件名"
  • 确认无误后，点击底部的红色/绿色 "Commit changes" 按钮
✅ 文件就被删除了，仓库里不再有这个文件。
⚠️ 注意：删除一个文件后，这个文件的历史记录仍然存在。你随时可以回到之前的提交记录找回它。不是彻底消失。

⛔ 删除整个仓库 危险操作

删除仓库会把里面的所有代码、Issues、Pull Requests 全部删掉，不可恢复。操作前一定要确认。

⚠️ 重要警告：删除仓库是不可逆的。一旦删除，里面的所有文件、提交记录、Issues、Wiki 全部消失，无法找回。除非仓库被 fork 过，否则数据彻底丢失。
1
进入要删除的仓库，点击顶部 "Settings"
打开你的仓库页面，在顶部导航标签栏（Code / Issues / Pull requests 那一行）的最右边，找到 "Settings"（设置），点击它。

📸 Settings 在导航栏最右边，如果窗口窄了可能在 "..." 折叠菜单里

Code Issues Pull requests Actions Projects Wiki Security Insights ① Settings
2
页面拉到最底部，找到 "Delete this repository"
进入 Settings 页面后，一直往下拉，拉到页面最底部。你会看到一个 红色区域的 "Delete this repository" 按钮。

📸 Danger Zone（危险区域）在 Settings 页面最底部，背景是红色边框，里面有删除仓库的按钮

Danger Zone
危险操作区
Delete this repository
3
按照提示输入仓库名确认
点击 "Delete this repository" 后，GitHub 会弹出一个对话框要求你输入要删除的仓库名称来确认（比如 你的用户名/仓库名）。
⚠️ 确认删除
请输入 你的用户名/仓库名 确认删除
输入仓库全名...
I understand, delete this repository
这个操作不可撤销，请确认
✅ 输入正确后，按钮会变成可点击状态，点击它仓库就彻底删除了。
4
删除后的页面
删除成功后，GitHub 会自动跳转到你的个人主页（github.com/你的用户名），刚才那个仓库已经不存在了。如果删错了，可以在几天内通过联系 GitHub 客服恢复，但不保证一定能找回。

📋 常见问题

❓ 仓库名能用中文吗？
不能。仓库名只能使用英文、数字、横线(-)、下划线(_)、点(.)。URL 地址不支持中文。
❓ 上传的文件有大小限制吗？
网页上传单个文件不能超过 25MB。大于 25MB 的文件需要用 Git 命令行或者 Git LFS。
❓ 私有仓库要收费吗？
GitHub 的免费账号可以创建无限数量的私有仓库，协作者不超过 3 人就不收费。超过 3 人需要付费。
❓ 公开仓库能改成私有吗？
可以的。在仓库 Settings 页面拉到最下面，Danger Zone 里有 "Change visibility" 选项，可以把公开改成私有。
❓ 误删了文件能恢复吗？
能。Git 会记录所有历史版本。在仓库页面点击 " commits"（提交历史），找到删除文件的那次提交，点进去把文件内容复制出来就行。
